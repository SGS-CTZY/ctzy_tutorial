# 承天之弈 · 初阵

[开始教学](https://sgs-ctzy.github.io/ctzy_tutorial/)

面向已熟悉基础三国杀的玩家，竖屏手机互动教学自动适配屏幕尺寸，共6章、41个步骤。包括区域高亮、武将卡面讲解、横置与重置、完整回合与弃牌顺序、界限突破、将军规则与被将状态。

弃牌阶段先休整武将至默认上限5名，再弃置手牌至当前体力值。最后一章演示双方使用将军规则，以及救援失败后判定胜负。

`index.html` 是完整独立版本，已内嵌图片、样式与互动逻辑；可直接在浏览器打开，也可下载离线使用。学习进度保存在当前设备。

GitHub Pages 使用 `main` 分支根目录。更新时替换 `index.html`，推送后自动发布。
